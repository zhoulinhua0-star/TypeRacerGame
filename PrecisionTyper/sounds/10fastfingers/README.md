# Keyboard sample provenance

These 28 unmodified MP3 recordings were retrieved on 2026-09-22 from
`https://10fastfingers.com/sounds/keys/` at the project owner's request.
The public typing-test client references A–Z, `space.mp3`, and `backspace.mp3`
and plays them at volume 0.3. PrecisionTyper uses the same volume and pitch.

`sources.json` records each source URL, file size, and SHA-256 digest.
There is no Enter, digit, or punctuation recording in this set: PrecisionTyper
uses Space for Enter and A for characters without a dedicated recording.

These are third-party recordings, not original PrecisionTyper assets. No reuse
license was supplied with the files; the repository's MIT license does not
grant rights to these recordings. No affiliation with 10FastFingers is implied.
